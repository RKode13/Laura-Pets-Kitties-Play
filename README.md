# Laura Pets Kitties — Play Online

The playable web version of **Laura Pets Kitties**.

**Play here:** https://rkode13.github.io/Laura-Pets-Kitties-Play/

- Computer: arrow keys to move, Space to pet / use, Q to stop.
- Phone: use the on-screen buttons (landscape works best).
- Progress saves in your own browser.

This repository only hosts the live game. Development happens in the main
(private) Laura-Pets-Kitties repository, and updates are copied here.
